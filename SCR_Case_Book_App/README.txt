SCR CASE BOOK: installable offline app

INSTALL (once, needs internet)
1. Upload this whole folder to any HTTPS host (GitHub Pages, Netlify, Cloudflare Pages are free).
2. Open the address on the tablet. Chrome/Edge: menu > Install app. iPad Safari: Share > Add to Home Screen.
3. After that it opens full-screen from its icon and works fully offline.
To share it, send others the same web address (or this zip for them to host).

DATA
Records live on each device. Use the Backup & cloud tab to export/import a backup file,
or to upload to your own WebDAV/HTTPS endpoint (the server must allow CORS).
